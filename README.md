# گزارش‌یار

ساخت سریع گزارش روزانه شعبه

## درباره پروژه

گزارش‌یار یک اپلیکیشن وب ساده و کاربردی است که به مدیران شعبه‌های هایپراستار کمک می‌کند تا گزارش‌های روزانه خود را به سرعت و با قالب استاندارد تولید کنند.

### ویژگی‌ها

- ✅ فرم جامع برای وارد کردن اطلاعات روزانه
- ✅ تولید گزارش به صورت زنده (Live Preview)
- ✅ کپی کردن آسان گزارش به کلیپبورد
- ✅ ذخیره‌سازی خودکار در مرورگر (localStorage)
- ✅ رابط کاربری فارسی RTL
- ✅ طراحی واکنش‌گرا (Responsive) برای موبایل
- ✅ بدون نیاز به بک‌اند یا دیتابیس
- ✅ استفاده از فونت وزیرمتن

## نصب و اجرا

### پیش‌نیازها

- Node.js (نسخه 18 یا بالاتر)
- pnpm (مدیریت بسته)

### نصب

\`\`\`bash
pnpm install
\`\`\`

### اجرای محلی (Development)

\`\`\`bash
pnpm dev
\`\`\`

سپس در مرورگر به آدرس `http://localhost:5173` بروید.

### ساخت نسخه Production

\`\`\`bash
pnpm build
\`\`\`

### پیش‌نمایش نسخه Production

\`\`\`bash
pnpm preview
\`\`\`

## استقرار در Vercel

1. پروژه را در GitHub/GitLab/Bitbucket آپلود کنید
2. به [Vercel](https://vercel.com) بروید
3. گزینه "New Project" را بزنید
4. مخزن پروژه را انتخاب کنید
5. تنظیمات پیش‌فرض را تایید کنید
6. "Deploy" را بزنید

Vercel به صورت خودکار پروژه را build و deploy می‌کند.

## تکنولوژی‌های استفاده شده

- **React 19** - کتابخانه UI
- **TypeScript** - Type Safety
- **Vite** - Build Tool
- **Tailwind CSS v4** - استایل‌دهی
- **Lucide React** - آیکون‌ها
- **Vazirmatn Font** - فونت فارسی

## نحوه استفاده

1. **اطلاعات گزارش**: تاریخ و نام شعبه را وارد کنید
2. **آمار فروش**: اطلاعات فروش روزانه را پر کنید
3. **شیفت‌ها**: اطلاعات مسئولین و حاضرین شیفت‌ها را وارد کنید
4. **نکات امروز**: رویدادها و نکات مهم روز را بنویسید
5. **نظافت**: ساعت و مسئول نظافت را مشخص کنید
6. **کپی گزارش**: با کلیک روی دکمه، گزارش کامل کپی می‌شود

## توجه

- اطلاعات فقط در مرورگر شما ذخیره می‌شود
- هیچ اطلاعاتی به سرور ارسال نمی‌شود
- با پاک کردن cache مرورگر، اطلاعات ذخیره شده پاک می‌شود
